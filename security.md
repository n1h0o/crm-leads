# Безопасность

- Приложение — локальный демонстрационный интерфейс, без сервера, авторизации, cookies, API и постоянного хранилища.
- Имена, компании, суммы и заметки синтетические; пользовательские изменения остаются в React state вкладки и удаляются после перезагрузки.
- Ввод показывается React как текст, HTML не интерпретируется.
- Перед подключением сервера потребуются аутентификация, серверная авторизация по каждой записи, журнал аудита, валидация, ограничение частоты и анализ угроз.
- Google Fonts обслуживается внешним источником как необязательный шрифтовой ресурс; системный fallback сохраняет интерфейс при его недоступности.
