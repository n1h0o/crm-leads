# Круг — CRM для команды продаж

Локальное демонстрационное приложение: CRM-воронка небольшой команды с канбан- и табличным режимами, поиском по заявкам, фильтром ответственного, стадиями сделки, заметками и добавлением новых лидов.

Все компании и контакты вымышлены. Приложение не подключает сервер или CRM-провайдера; данные остаются в памяти текущей вкладки и сбрасываются после перезагрузки.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```
